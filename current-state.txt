# Micro-Investing Assistant - Current State (2026-05-03)

## Project Overview
Building a beginner-safe micro-investing assistant that helps users with small monthly savings understand how to start investing responsibly. Uses behavioral clustering on financial data to segment users into 3 categories and provide structured investment recommendations with AI-generated explanations via NVIDIA NIM LLMs.

## Completed Features (Detailed)

### 1. ML Pipeline (COMPLETE - Working)
**Source:** `ml_part.ipynb` | **Artifacts:** `app-core/backend/ml_artifacts/`

**What's implemented:**
- Loaded 20,000-row Indian personal finance dataset (synthetic + crowdsourced)
- Built behavioral feature engineering:
  - `Savings_Ratio`: (Income - Expenses) / Income
  - `Expense_Ratio`: Expenses / Income
- Trained KMeans clustering with 3 behavioral clusters
- Implemented dynamic segment mapping (clusters sorted by median savings ratio)
- Safety guardrails:
  - Negative/zero savings → forced to "Financially Stressed"
  - Savings ratio <10% → capped to "Cautious Saver"
- Saved all artifacts: imputer.pkl, robust_scaler.pkl, kmeans_model.pkl, segment_map.json, feature_order.json

**Segment Definitions:**
| Segment | Multiplier | Investment Appetite | Risk Level |
|---------|-----------|---------------------|------------|
| Financially Stressed | 0.0 | Zero | Critical |
| Cautious Saver | 0.2 | Low-to-Medium | Low |
| Investment Ready | 0.4 | High | Medium |

### 4. SIP Calculator (Feature 13 - COMPLETE)
**Files:** `utils/sip_calculator.py`, `routes/api.py`, `models/schemas.py`

**What's implemented:**
- SIP (Systematic Investment Plan) future value calculation
- Formula: `FV = P × [{(1 + r)^n - 1} / r] × (1 + r)`
  - P = Monthly investment
  - r = Monthly return rate (annual % / 12 / 100)
  - n = Total months (years × 12)
- Returns:
  - Future value (formatted with rupee symbol)
  - Total invested amount
  - Total growth
  - Growth percentage
- Input validation:
  - Monthly investment > 0
  - Years: 1-50
  - Expected return: 1-30%

**API Endpoint:**
- `POST /api/v1/calculate-sip` - Calculate SIP returns
- `GET /api/v1/sip-examples` - Get example SIP scenarios

**Example Request:**
```json
{
  "monthly_investment": 5000,
  "years": 10,
  "expected_return": 12
}
```

**Example Response:**
```json
{
  "monthly_investment": 5000,
  "years": 10,
  "expected_return": 12,
  "future_value": 114915.87,
  "total_invested": 60000,
  "total_growth": 54915.87,
  "growth_percentage": 91.53,
  "formatted_future_value": "₹1,14,916"
}
```

### 5. Emergency Fund Readiness Check (Feature 14 - COMPLETE)
**Files:** `utils/financial_diagnosis.py`, `services/recommendation_service.py`

**What's implemented:**
- Auto-detects if user has < 3 months of expenses saved
- Generates tiered alerts based on corpus vs. target:

**Alert Levels:**
1. **CRITICAL** (emergency_fund_missing): No emergency fund
   - Message: "CRITICAL: You have NO emergency fund. Build ₹X,XXX (3 months expenses) BEFORE any investing."
2. **WARNING** (emergency_fund_incomplete): Partial fund (< 6 months)
   - Message: "WARNING: Your emergency fund (₹X,XXX) is incomplete. Target: ₹X,XXX (6 months). Prioritize building this buffer before aggressive investing."
3. **INFO** (emergency_fund_adequate): Full fund (≥ 6 months)
   - Message: "Good: You have an adequate emergency fund (₹X,XXX). You can proceed with investment recommendations."

**Logic:**
- Target = 3 months expenses (minimum)
- Full target = 6 months expenses (ideal)
- High income guardrail: If income > ₹5L/month, cap emergency fund calculation to prevent absurd values

### 7. Goal-Based Input & Allocation (Feature 17 - COMPLETE)
**Files:** `models/schemas.py`, `utils/goal_allocation.py`, `services/recommendation_service.py`

**What's implemented:**
- User can specify financial goals during input
- Supported goals:
  - Retirement
  - Child Education
  - Home Purchase
  - Wealth Building
  - Travel
  - Education Upskilling

**Goal Descriptions:**
- Retirement: "Long-term wealth creation for post-work life"
- Child Education: "Funding future educational expenses"
- Home Purchase: "Saving for property down payment"
- Wealth Building: "General wealth accumulation"
- Travel: "Short-term experiential goals"
- Education Upskilling: "Professional development investments"

**Allocation Logic:**
- Distributes surplus across selected goals based on priority
- High priority goals get 40-50% allocation
- Medium priority goals get 25-35% allocation
- Low priority goals get 10-20% allocation
- Returns monthly amounts and percentages per goal

**API Integration:**
- `goals` field in `UserFinancialInput` schema
- Passed through to `compute_goal_based_allocation()` function
- Included in final response as `portfolio.allocations`
