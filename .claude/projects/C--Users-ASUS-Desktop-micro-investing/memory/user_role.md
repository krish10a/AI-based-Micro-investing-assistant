# User Role

## Role Context
The user is actively developing and fixing a micro-investing application. They are focused on resolving data flow issues between the frontend and backend, particularly around the onboarding process and subsequent data usage in various application pages.

## Knowledge Level
- Strong understanding of Next.js and TypeScript frontend development
- Familiarity with React hooks, state management, and data fetching patterns
- Understanding of REST API consumption and localStorage usage
- Ability to diagnose and fix data mapping issues between API responses and UI components
- Experience with debugging UI issues related to missing or incorrect data

## Current Focus
The user is specifically working on:
1. Fixing data flow from onboarding to other application pages (goals, analysis, dashboard, chat)
2. Ensuring proper data storage and retrieval from localStorage
3. Correcting property mapping issues in data transformation functions
4. Resolving UI display problems caused by missing or incorrect data
5. Verifying that all components receive and display the correct financial data after onboarding

## Working Style
- Prefers concrete, actionable fixes over theoretical discussions
- Wants to understand root causes before implementing solutions
- Values verification steps to confirm fixes work correctly
- Focuses on end-to-end data flow correctness
- Appreciates clear explanations of what was broken and how it was fixed

## Goals
- Have all application pages display correct data after onboarding
- Eliminate "₹0" values and empty states caused by data flow issues
- Ensure AI chat has proper context about user's financial situation
- Fix misleading or incorrect alerts (like the emergency fund warning)
- Have health score and other visualizations display accurately
