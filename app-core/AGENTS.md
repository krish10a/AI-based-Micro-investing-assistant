# AGENTS.md — Micro-Investing Assistant

## Project Scope
Beginner-safe micro-investing assistant. **Not a stock-picking engine.** Educational positioning only (not SEBI-registered). 3 behavioral clusters: Financially Stressed, Cautious Saver, Investment Ready.

## Repo Boundaries
- `app-core/` is the **only** folder that goes to GitHub. All work stays inside it.
- `app-core/backend/` = FastAPI backend (production code)
- `app-core/micro-invest-ui/` = Next.js 16 frontend
- `app-core/ui/` — ignore, scratch directory
- Root-level files (`ml_part.ipynb`, `current-state.txt`, etc.) are reference notes, NOT part of the deployable project.
- `free-claude-code/` — separate project, ignore for this repo.

## Commands

### Backend (Python/FastAPI)
Workdir: `app-core/backend`

```powershell
cd app-core/backend; uv run uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

```powershell
cd app-core/backend; uv run pytest                           # Run all tests
cd app-core/backend; uv run pytest tests/test_feature_engineering.py -v  # Just feature eng tests
```

**Note:** No `pyproject.toml` exists. Install with `uv pip install -r requirements.txt` or just `pip install -r requirements.txt`. The SETUP_INSTRUCTIONS mention `uv sync` but there's no lockfile — use requirements.txt.

### Frontend (Next.js 16)
Workdir: `app-core/micro-invest-ui`

```powershell
cd app-core/micro-invest-ui; npm run dev      # Dev server
cd app-core/micro-invest-ui; npm run build    # Production build
cd app-core/micro-invest-ui; npm run lint     # ESLint
```

## Environment
- Required env var: `NVIDIA_NIM_API_KEY` (set in `backend/.env`)
- Default port: `8000` (not 8001)
- ML artifacts dir: `backend/artifacts/` (`.gitignore`d — contains `imputer.pkl`, `robust_scaler.pkl`, `kmeans_model.pkl`, `segment_map.json`, `feature_order.json`)

## Architecture (Fixed Flow)
```
User → Frontend (Next.js) → FastAPI validation → ML inference → Policy guardrails → NIM explanation → Response
```
**Frontend NEVER queries ML or NIM directly.** Backend owns all intelligence.

## ML Pipeline
- Source of truth: `ml_part.ipynb` (root level). This notebook is verified working.
- Feature engineering in `backend/utils/feature_engineering.py` must match training pipeline exactly. Train-serve parity is critical.
- Inference sequence: validate → compute features → apply saved imputer → apply saved scaler → predict cluster → map to segment → apply guardrails → return.

## NIM Fallback
5-model pool with automatic fallback: `llama-3.1-70b` → `mistral-medium-3.5-128b` → `gemma-4-31b` → `qwen3-next-80b` → `llama-3.1-405b`. Falls back to rule-based explanation if all fail. Check health at `GET /api/v1/model-health`.

## UI Constraints
- UI is generated by the user using **Google Stitch Labs**, NOT by the agent.
- Agent only wraps UI when user explicitly says: **"wrap our project with stitch ui"**.
- Do NOT build or modify UI files unless explicitly commanded.
